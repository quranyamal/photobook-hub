# PhotoBook Hub MVP Scope

## Goal

Validate that customers are willing to purchase personalized photobooks online.

## Included

### Customer

* Create project
* Upload photos
* Basic photobook editor
* Select photobook size
* Preview photobook
* Place order

### Admin

* View orders
* Download print-ready assets
* Update order status

### Production Team

* Manual workflow outside system

### Payments

* Manual bank transfer

## Excluded

* Social login
* Mobile app
* Advanced editor
* AI layout generation
* Coupons
* Referral system
* Multi-language
* Multi-country support
* Production team portal
* Automated fulfillment

## Success Criteria

* End-to-end order flow works
* Customer can receive a printed photobook
* In-house production team can fulfill orders
